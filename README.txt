LANDING PAGE — KEDAI POJOK MBA LUTFI
REVISI SEMUA GAMBAR MENU + SUBTOTAL DINAMIS

File utama:
- index.html
- styles.css
- script.js
- folder assets/

Cara membuka:
1. Ekstrak ZIP.
2. Buka file index.html melalui browser.
3. Pilih menu dan klik tombol “Tambah”.
4. Buka “Pesanan” untuk melihat rincian dan subtotal.

Perubahan pada versi ini:
- Gambar header menu diperbarui menggunakan materi terbaru.
- Seluruh gambar kartu makanan diperbarui: Lumpia Beef, Bakso Sapi Asli Tetelan, Mie Ayam Ceker Pangsit, dan Bakso Telur.
- Seluruh gambar kartu minuman diperbarui: Milo Ice, Kopi Susu, Es Teh, Es Jeruk, dan Pop Ice.
- Komposisi poster menu ditampilkan utuh tanpa memotong logo, produk, atau nama menu pada gambar.
- Seluruh gambar dioptimalkan ke format WebP agar halaman lebih ringan saat dibuka.
- Subtotal otomatis mengikuti makanan, minuman, dan jumlah item yang dipilih.
- Subtotal makanan dan subtotal minuman ditampilkan secara terpisah.
- Menu yang masih berstatus “Konfirmasi harga” tidak dimasukkan ke subtotal agar total tidak menyesatkan.
- Rincian pesanan dan subtotal otomatis ikut disusun ke dalam pesan WhatsApp.

Data yang masih perlu dilengkapi sebelum publikasi:

Catatan teknis:
- Harga menu dapat diubah pada atribut data-price di index.html.
- Contoh: data-price="12000" akan dibaca sebagai Rp12.000.
- Pastikan harga yang ditampilkan pada kartu menu sama dengan nilai data-price.
